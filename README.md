# Luna — Interactive 3D Moon Atlas

A standalone WebGL 2 Moon viewer with embedded NASA Lunar Reconnaissance Orbiter imagery and elevation data. Open `index.html` in a modern browser. No server, build step, dependencies, or internet connection are required.

## Features

- Rotate, zoom, and explore both lunar hemispheres and poles.
- Natural-color and relative-elevation views, adjustable terrain relief, coordinate grid, lunar phase lighting, and shadow fill.
- Interactive landmarks, including all six crewed Apollo landing sites.
- Auto-rotation, fullscreen, and PNG screenshot export.

## Data credit

NASA Scientific Visualization Studio, [CGI Moon Kit](https://svs.gsfc.nasa.gov/4720), based on LROC imagery and LOLA elevation data. The terrain and lighting are intended for visualization rather than scientific measurement or live ephemerides.
